# Molo Opportunities Website
A responsive frontend prototype for a local jobs, attachments, internships, volunteering, scholarships and courses platform.

## Run
Open `index.html` in a browser. No server is required for this prototype.

## Next production steps
- Connect registration/login to a secure backend.
- Add a database for users, employers and vacancies.
- Add real application submission and employer dashboards.
- Add email/SMS notifications and payment integration.
